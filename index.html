О проекте

Откуда данные

Публичный Steam Store (search specials + регионы). Цены ориентировочные, клик ведёт в официальный магазин.

Популярные / жирные

Список известных appid + автодобавление скидок ≥70%, если совпадений мало. Можно выключить фильтр.

Трейлеры

На десктопе при наведении подгружается трейлер Steam (без звука). На телефоне — только картинка.

Обновление

GitHub Actions раз в 6 часов. Ручной запуск: Actions → Update Steam deals.
